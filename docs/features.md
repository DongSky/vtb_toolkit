# VTB Toolkit — 已有功能总览

> 本文只描述当前已经包含的功能。开发计划与历史完成状态见 [roadmap.md](roadmap.md)。

VTB Toolkit 是面向虚拟主播、场控、录播与切片/烤肉创作者的桌面工具。它把直播间管理、弹幕、录制、实时字幕、离线分析、切片复盘和创作素材导出放在同一个本地工作流中。

## 一条完整的使用路径

1. 在「账号」页扫码登录 B 站，获得完整用户名弹幕与原画取流能力。
2. 在「房间」页维护常用直播间，连接弹幕或启动录制。
3. 直播中查看/翻译弹幕、场控发言、实时字幕，并把弹幕或同传字幕输出到 OBS。
4. 直播中用按钮、全局快捷键或房管弹幕口令打点；疑似高能片段也可自动打点。
5. 下播后运行「离线处理」，生成字幕、翻译、高能片段和切片。
6. 在「复盘」页查看高能时间轴、场次数据和封面建议，导出切片、时间戳、剪辑工程或完整素材包。

## 已有功能

### 中英日国际化与图文教程

- 简体中文、English、日本語即时切换并保存，覆盖主界面、提示、主题、模型说明与 OBS 独立页面。
- 识别语种与翻译目标独立设置；昵称、评论、备注、术语和用户投稿内容保持原文。
- Markdown 场次报告按界面语言导出；机器可读的 CSV/JSON 字段保持稳定。
- 内嵌离线三语图文教程，含 20 个章节、目录、搜索、截图放大和打印 PDF。
- [打开图文教程](user-guide.html)；[开发维护说明](internationalization.md)。

### YouTube 与独立评论网页

- 使用 YouTube.js 18.0.0 匿名读取公开评论、Super Chat、Super Sticker、会员及会员礼赠；支持去重、重连、删除/替换和自定义表情。
- 收藏直播/频道、开播监控、yt-dlp 分离音视频取流、分段录制；复用评论日志、打点、高能、通知、保留策略及复盘导出。
- 字幕支持 B 站与 YouTube 来源，每个任务可分别停止；观众备注按原始平台身份隔离，收入报告按明确币种分组。
- OBS 默认固定端口 18990，提供独立透明网页、复制/打开 URL、双平台混合或独立直播筛选、主题及显示设置、实时预览。
- YouTube 投稿采用 Google 官方桌面 OAuth、系统凭据库和分块续传，默认私享；真实账号授权与投稿尚未进行端到端验证。不提供 YouTube 评论发送。
- 详细操作、平台差异与依赖见 [使用指南](youtube-and-obs.md)。

### 账号与配置

- B 站手机客户端扫码登录、登录状态恢复与退出登录。
- 登录凭据保存在系统钥匙串；登录后可显示完整弹幕用户名并请求原画画质。
- 房间号、目录、模型、录制、翻译等常用界面配置本地持久化。
- “设置 → AI 服务”统一管理文本、视觉和图片生成，支持保存、清除密钥、连接测试及生效来源显示。文本和视觉支持 Anthropic / OpenAI 兼容接口；视觉默认复用文本，也可单独配置。图片测试只查询模型列表。

### 房间管理

- 保存多个 B 站直播间，展示封面、主播、分区和直播状态。
- 每个房间可独立连接弹幕、开始录制或停止录制。
- 房间信息每 30 秒自动刷新。

### 弹幕与场控

- 实时接收和显示 B 站弹幕、礼物、SC、舰长等直播事件。
- 弹幕连接支持断线重连、服务器 failover 和登录态。
- 3 套内置主题；支持可视化编辑、自定义主题和 JSON 导入导出。
- 弹幕自动翻译，可选择中文、英语、日语或韩语；App 与 OBS 叠加层同步显示译文。
- 点击用户名添加备注，并保留跨场次观众备注/画像。
- 登录后可发送弹幕，并支持：
  - 礼物、舰长和 SC 自动答谢模板；
  - 定时弹幕；
  - 发送限频与重复码处理。
- Twitch 匿名聊天接入，共用弹幕展示、翻译与 OBS 输出链路。

### 直播打点

- 录制期间可通过三种方式手动打点：
  - 弹幕页按钮，可附备注；
  - 全局快捷键 `Cmd/Ctrl+Shift+M`；
  - 房管发送「打点 [备注]」弹幕口令。
- 实时 highlight 检测可在弹幕峰值出现时告警并自动落盘。
- 打点统一对齐录制会话时间轴，写入 `markers.jsonl`。
- 离线分析会把人工打点作为高能候选的强先验。
- 可导出 `timestamps.txt`，格式可直接用于 B 站评论或简介。

### 自动录制

- B 站开播监听、自动取流和 ffmpeg 无损录制。
- 支持不切分、按时长切分和按文件大小切分。
- 录制时同步保存弹幕日志与会话元数据，供后续离线分析自动使用。
- 断流 watchdog、流 URL 重新获取、备线切换和分段续录。
- 录制结束后自动进行 FLV tag 级时间戳修复与 MP4 remux。
- 磁盘空间安全检查；可按保留天数、每房间场次数或目标剩余空间滚动清理旧录播。
- 可将开播、录制完成和异常推送到 Bark、ServerChan、Telegram 或自定义 Webhook。
- 支持通过 `yt-dlp` 监听并录制 YouTube/Twitch URL。

### 实时字幕与同传

- 基于 whisper.cpp 的本地语音识别，支持中、英、日及自动语种检测。
- 自适应 VAD 分句与常见 Whisper 幻觉过滤。
- 内置模型列表与下载管理，可选择不同大小的 Whisper 模型。
- 可选 LLM 同传翻译，支持滚动上下文、重试、有界并发和用量统计。
- 实时显示原文与译文，并同步发送到 OBS 字幕叠加层。

### 热词表

- 用自然语言或任意文本格式录入人名、游戏术语、梗、别名、读音和固定译法。
- 可用 LLM 自动规整，也可使用本地规则解析。
- 支持查看、删除词条，以及合并多个热词表。
- 热词表可分别用于实时字幕和离线处理，提高识别与翻译准确率。

### OBS 浏览器源

- 启动仅监听本机的 HTTP/WebSocket 叠加层服务。
- 提供弹幕层和同传字幕条两个 OBS 浏览器源 URL。
- 支持通过 URL 参数调整字号、宽度、保留行数和字幕停留时间。
- 同一服务提供 `/api/status`，供本地自动化读取弹幕连接与录制状态。

### 离线处理

给定完整录播文件后，可自动执行：

1. 提取音频；
2. Whisper ASR；
3. 可选 LLM 翻译；
4. 导出 SRT 与双语 ASS 字幕；
5. 综合弹幕密度、情绪关键词、礼物/SC 和音频能量检测高能片段；
6. 可选按时间戳分块发送 ASR 文本，让 LLM 从内容本身识别梗、反转、情绪与操作高光；
7. 可选对全片按可调间隔抽帧，由 Anthropic 或 OpenAI 兼容视觉模型发现画面高光；
8. 语义、画面与传统信号候选分别保留证据，自动添加前后冗余、合并重叠区间并限制切片数量；
9. 批量导出切片，可选烧录双语字幕；
10. 可选歌切模式，检测并单独导出歌曲段落。

AI 粗剪默认关闭以避免意外 API 成本。界面可设置前后冗余、抽帧间隔和最大切片数；单批请求失败时会跳过该批，传统信号结果仍可继续导出。

录制产生的同目录弹幕日志会被自动发现，也可以手动指定其他 JSONL 弹幕日志。

### 录播复盘与切片

- 高能进度条同时显示弹幕密度、音频能量和高能区间。
- 时间轴叠加人工/自动打点、SC、舰长和开播事件。
- 点击时间轴跳转内置播放器；拖选任意区间后无损导出切片。
- 查看高能片段、已有切片和打点事件，直接预览切片。
- 生成 720p 低码率代理副本，方便长录播粗剪。
- 生成场次报告，包括：
  - 弹幕数、独立发言人数和营收汇总；
  - SC 清单；
  - 弹幕词云；
  - 发言榜；
  - Markdown 与 CSV 导出。
- 可调用 `biliup` 将切片一键投稿到 B 站。

### 剪辑软件与素材导出

- 导出 CMX3600 EDL。
- 导出带高能片段和打点 marker 的 FCPXML，可导入 Final Cut Pro 和 DaVinci Resolve。
- 导出剪映 5.x 格式草稿目录。
- 一键导出素材包，集中包含切片、双语字幕、弹幕 XML、时间戳清单与封面候选帧。
- 导出 B 站/录播姬兼容弹幕 XML，可再交给 `danmaku2ass` 等工具转换。

### 封面辅助

- 从高能片段密集抽取 1280px 候选帧。
- 根据高能标题、场次报告、热词、字幕节选和补充信息生成多组封面创意，包括标题、副标题、构图、配色、平台比例和图像 prompt。
- 在复盘页浏览候选帧和创意方案。
- 支持调用 OpenAI 兼容的图像接口生成封面概念图：
  - 纯文本生成；
  - 选择候选帧或本地图片作为参考图；
  - 自定义 API Base、模型和尺寸；
  - 图像 API Key 独立保存于系统凭据库，重启后仍有效，不写入普通配置或安装包。

### 自动化与扩展

- 开播、录制完成和异常支持 HTTP Webhook。
- 本地状态 API：叠加层服务运行时可访问 `/api/status`。
- 脚本钩子可在录制开始和结束时触发本地脚本，并通过 stdin 传入 JSON；单次执行超时为 30 秒。当前需直接编辑 settings 配置，没有设置界面。
- Rust workspace 将弹幕、录制、ASR、翻译、highlight、统计和离线管线拆分为独立 crate，便于继续扩展。

### 已包含但尚未接入界面的能力

以下代码和后端命令已包含在项目中，但普通用户当前不能从 App 界面直接使用：

- macOS 弹幕 TTS 控件与后端命令；
- 录制流 tee PCM 给实时字幕的单流复用选项；
- 手动 FLV 修复命令；
- 取消正在运行的离线任务；
- 多平台 URL 探测；
- 主播翻译 profile 命令；
- 脚本钩子配置。

## 主要输出文件

一次录制与离线处理可产生以下内容（按启用的功能有所不同）：

- 录播分段、修复后的 FLV/MP4 与 `meta.json`；
- `danmaku.jsonl`、`markers.jsonl`、弹幕 XML；
- transcript、SRT、ASS 与双语字幕；
- `signals.json`、`highlights.json`、`semantic_candidates.json`、`visual_candidates.json` 与切片文件；
- `timestamps.txt`、场次报告 Markdown、SC CSV；
- EDL、FCPXML、剪映草稿、720p proxy 与素材包；
- `cover/` 候选帧、`ideas.md` 与生成的封面图。

## 依赖与已知限制

- Windows 已验证完整功能构建、内嵌网页程序启动、真实双平台评论及独立网页输出；需账号/模型的外部服务仍须结合用户配置验证。Linux 尚未完成全功能验证。
- 录制、抽帧、切片、字幕烧录等功能依赖 PATH 中的 `ffmpeg`；字幕烧录要求 ffmpeg 带 `libass`。
- AI 画面扫描要求所选模型支持图片输入；稀疏抽帧适合发现反应、结果画面和视觉梗，但不能保证捕捉两帧之间发生的极短操作，缩短抽帧间隔会增加 API 成本。
- 多平台录制依赖 `yt-dlp`；YouTube 和 Twitch 聊天默认匿名读取，受限制直播可能无法匿名访问。
- 实时字幕目前只在内存中展示，不单独保存历史；需要离线处理才能导出 SRT/ASS。
- 弹幕过滤规则（黑名单、等级或礼物门槛）尚未实现。
- 弹幕 TTS 后端当前使用 macOS `say`，且控件尚未挂入主界面。
- 录制侧已具备单流字幕复用能力，但当前录制界面没有开关；「实时字幕」页仍会独立拉流。
- 剪映草稿导出按 pyJianYingDraft 5.x 结构实现，属于实验性功能，可能需要针对本机剪映版本调整。
- 弹幕 XML 尚未内置转换为 ASS，需要使用 `danmaku2ass` 等外部工具。
- 应用尚未提供签名安装包、自动更新与正式分发渠道。
- 使用录制、弹幕、投稿和 AI 接口时，请自行遵守平台条款、主播二创授权和对应服务的隐私/计费规则。
