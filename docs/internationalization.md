# 界面国际化与教程维护

界面提供 `zh-CN`、`en`、`ja`。初次启动参考系统语言；之后优先恢复用户选择。选择即时写入 WebView 本地存储与 Tauri 配置 `ui.locale`，配置读取的慢响应不能覆盖刚选的新语言，连续写入按顺序执行。

`src/i18n/` 的 JSON 使用中文原文作为键，值为 `[English, 日本語]`。组件调用 `useLocale()` 订阅切换，通过 `t("完整句子 {0}", value)` 显示文案。不要拼接中文片段来组成译文。带原始后台状态的展示边界使用 `tm()`；需要保存延迟提示时使用 `sourceText()`，避免把当前译文存入状态后无法再次切换。

昵称、评论、热词表内容、自定义主题名、备注、AI 输出和用户编写的投稿字段保持原文。不要把这些数据传入 `tm()`。未知第三方错误也保留原始诊断。CSV 列名与机器可读 JSON 保持稳定；Markdown 场次报告的系统标签按界面语言导出。

实时字幕/离线处理的 `asr_lang` 和 `target_lang` 由各自表单持久化，与界面语言独立。OBS 地址携带 `lang` 参数，独立页面只翻译状态、标签和辅助文字。

## 教程构建

- 维护 `docs/guide/content.mjs`，每个段落含中、英、日三份等覆盖正文。
- 实际 Windows 界面截图位于 `docs/guide/images/`，命名 `功能-语言.png`。复盘示例包含明确标识的教程数据，不是实测高能结果。
- 执行 `npm run docs:build`，生成 `docs/user-guide.html`、三份 Markdown，以及内嵌资源 `public/guide/index.html`。HTML 自包含，可离线阅读、搜索、三语切换、图片放大及打印 PDF。
- `/guide` 路由将教程编译进本地叠加层服务。修改教程后先重建教程、前端，再构建原生应用。
- `npm test` 检查词库占位符、语言持久化竞态、用户内容保留、独立评论页面以及教程的三语目录和搜索。

## 验证范围

Windows 原生窗口已检查即时切换和重启恢复。远端 OAuth、投稿和付费 AI 需在用户自己的账号及服务环境验证；此次国际化测试没有执行这些外部动作。仓库原有的 workspace 格式与 Clippy 告警单独保留，未为此批量修改无关模块。
